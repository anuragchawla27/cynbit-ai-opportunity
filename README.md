# Cynbit Intake Copilot

AI/ML Engineer Intern assessment for Cynbit Technologies: *Identify an AI Opportunity for Cynbit*.
Author: Anurag Chawla.

**Idea:** Cynbit gets two kinds of inbound demand, business clients and students, and sells AI agents that "manage leads and coordination". This project applies that to Cynbit itself: it triages inquiries, answers questions from a sourced knowledge base, retrieves similar past work, and routes students to BitElevate.

## What the app does

1. **Ask Cynbit:** answers questions with a citation on every line; each source is tagged *verified*, *claimed by Cynbit* or *inference*.
2. **Triage a client inquiry:** rule-based lead score with breakdown, ML probabilities (Cold/Warm/Hot), similar past case studies, and a discovery-call brief.
3. **BitElevate track match:** recommends one of the 16 tracks and a duration for a student.

No API key is needed. Everything runs offline.

## Quick start

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate      macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Run the tests and reproduce the evaluation:

```bash
python -m pytest -q
python scripts/train_eval.py
```

The model is trained on first use if `models/lead_model.joblib` does not exist.

## Results (honest summary)

Trained on 1,500 synthetic inquiries, tested on 30 hand-written ones:

| Method | Hand-written macro-F1 |
|---|---|
| Rule-based baseline | 0.54 |
| Logistic regression, text only | 0.44 |
| Logistic regression, text + signals | **0.71** |

Text-only memorises the generator's phrasing; engineered signals fix most of that. **Known weakness:** Warm recall is 0.30. The data is synthetic and the test set is small, so these numbers show that the method works, not production accuracy. Details and threats to validity are in the Technical Approach Report.

## Data provenance

`data/kb/cynbit_kb.json` holds 26 chunks from Cynbit's public website, registry listings, GitHub, and screenshots of its Instagram and LinkedIn pages. Each chunk has a source URL and a status. Many company figures (1000+ students, 50k+ lives, 25k newsletter) are Cynbit's own claims and are labelled as such. LinkedIn posts, Instagram reel video and Reddit could not be accessed. There is no public Cynbit inquiry log, so lead training data is generated by `src/lead_data.py`.

## Limitations and next steps

Synthetic training data, a 30-message test set, keyword-based service matching, English only, and no LLM layer (a design is in the Technical Approach Report). Next: train on real labelled inquiries, fix Warm recall, add a human-approved LLM brief, pilot with one founder.
